# Holy Diver HD v1.0.1

Fixes original NES graphics appearing in the later Poison Moss Land lava-curtain corridor.

## Fixes

- Apply the existing animated HD lava to the vertical curtain, including both hot palette phases and its matching frozen form.
- Keep the horizontal lava pool in HD while Blizzard is active.
- Complete the mossy ceiling details and platform contours that still used original tiles.
- Preserve native gameplay, collision, timing, music and sound effects.

## Install or update

Download **Holy_Diver_HD_v1.0.1.zip** below. Extract every file into the HD pack folder matching your ROM filename without `.nes`, replacing the previous pack files. For `HolyDiverHD.nes`, the main file belongs at `HdPacks/HolyDiverHD/hires.txt`. Close the game and reopen it after updating.

Tested with **MesenCE 2.2.1** and the supported translated ROM, SHA-1:
`FE2FCD0AD334D792DB16535D09F3AB9FB2BEA3AC`.

See the [Windows and macOS installation guide](https://github.com/kgrant191/holy-diver-hd/blob/v1.0.1/docs/INSTALLATION.md) for full setup instructions.
