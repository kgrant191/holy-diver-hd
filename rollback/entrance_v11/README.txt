HOLY DIVER HD v11 — UPWARD FIRE

Up + B now uses HD Randy and vertical firebolts, with normal and Twin Fire
versions. Grounded, mirrored and airborne upward casts share the new artwork.
The approved v10 sound correction and all other artwork are retained.

1. Back up the previous pack. Install this complete ZIP with Mesen's HD-pack
   installer, or extract hires.txt, Entrance_SFX_Priority.ips and every PNG into
   <Mesen data folder>/HdPacks/Holy_Diver_(Tr)/.
2. The folder name must match the ROM filename without .nes. Enable HD packs.
3. Fully close and reopen the ROM to reload the pack and retained sound patch.
4. Continue with the approved Holy_Diver_HD_v10_Entrance.mss, or start fresh.
   Original pre-v10 save states retain the old audio priorities.

Up + B fires upward; B fires forward; Select equips/unequips Twin Fire;
A jumps; Start opens/closes pause. No Lua script is needed to play.

Supported original ROM SHA-1: fe2fcd0ad334d792db16535d09f3ab9fb2bea3ac
Mesen applies the two-byte sound patch in memory. The ROM file is not edited.
Do not manually apply the IPS. The compatible state requires MesenCE 2.2.1;
on Mesen 2.1.1 start a new game. No ROM or emulator is included.

To roll back this artwork update while keeping the sound fix, install the full
v10 pack from the source archive's rollback/entrance_v10 and reload the ROM.
