INSTALLATION
1. Back up your current HD-pack folder.
2. Extract every file directly into the folder matching your ROM name:
   Mesen/HdPacks/Holy_Diver_(Tr)/
   hires.txt must be directly in that folder, with no nested folder.
3. Enable NES HD packs. Fully close the ROM and reopen it to reload the pack.
4. Start a new game or load your existing state.
